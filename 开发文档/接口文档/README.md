# 接口文档目录

本目录按接口形态分为两个子目录：

- `后端接口/`：前端与后端之间的 RESTful API 文档（JSON 格式）
- `算法接口/`：算法模块之间/对外的 Python 接口文档（sklearn 风格）

## 文件清单

### 后端接口/

| 文件 | 用途 |
|---|---|
| 接口模板.md | 新建接口文档的复制模板 |
| 通用约定.md | Base URL、认证、响应格式、错误码、分页等全局约定 |
| 管理员接口.md | 管理员注册/登录/数据管理接口（FR-01/02） |
| 实时数据接口.md | 人流密度、热力图、密度预测数据接口（FR-27） |
| 交通网络接口.md | 节点监控、热度指标、最短路径接口（FR-06~09） |
| 门闸接口.md | 门闸状态与开闭策略接口（FR-19） |
| 车辆准入接口.md | 车辆准入决策接口（FR-13） |
| 预警接口.md | 预警事件查询与入库接口（FR-22/23） |

### 算法接口/

| 文件 | 用途 |
|---|---|
| 接口模板.md | 新建算法接口文档的复制模板 |
| 接口规范.md | sklearn 风格接口总约定（引用《变量及接口命名规范.md》） |
| 宏观算法.md | 宏观拓扑/最短路径/热点分析算法接口 |
| 微观与车辆算法.md | CAV 仿真/车辆准入/差分隐私算法接口 |
| AI模型接口.md | 人流密度预测/异常检测算法接口 |
| 仿真与调控接口.md | 门闸策略/宏微联合调控算法接口 |

## 维护规则

- 新增接口时先复制对应模板，按模板填写
- 接口变更时同步更新对应文档，保证与代码一致
- 各文档回链需求分析的 FR 编号，方便对照
