## 完整示例：管理员登录

- **方法/路径**：POST /api/v1/admin/login
- **功能**：管理员登录，成功返回访问令牌
- **权限**：公开
- **对应需求**：FR-01

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | string | 是 | 管理员账号 |
| password | string | 是 | 登录密码 |

### 请求示例

```json
{
  "username": "admin",
  "password": "123456"
}
```

### 响应示例

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "token": "eyJhbGciOi..."
  }
}
```

### 错误码

| 错误码 | 含义 |
|---|---|
| 40101 | 账号或密码错误 |
