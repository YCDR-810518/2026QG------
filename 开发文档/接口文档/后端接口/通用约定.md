# 通用约定

> 本文件定义所有后端接口的全局约定，各业务接口文档不再重复。

## Base URL

待补：统一前缀，如 `http://<host>:<port>/api/v1`

## 认证方式

待补：登录后返回 token（如 JWT），后续请求在 Header 携带 `Authorization: Bearer <token>`

## 统一响应结构

待补：约定响应 JSON 结构，如：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```
