# 通用约定

> 本文件定义所有后端接口的全局约定，各业务接口文档不再重复。

## Base URL

统一路由前缀为：`/api/v1`[cite: 14, 15, 16]。
完整请求路径示例：`http://<host>:<port>/api/v1/...`

## 认证方式

平台接口统一要求需登录才能访问[cite: 14, 15, 16]。登录后后端返回 token，后续请求必须在 HTTP Header 中携带该 token 进行鉴权，格式如下：
`Authorization: Bearer <token>`

## 统一响应结构

待补：约定响应 JSON 结构，如：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

其中 `code=0` 表示请求成功[cite: 14, 15, 16]，非 `0` 表示发生特定业务错误；`message` 提供简要说明；实际业务数据存放在 `data` 对象中。

## 错误码区间

| 错误码 | 含义       | 覆盖场景说明                                                 |
| ------ | ---------- | ------------------------------------------------------------ |
| 0      | 请求成功   | 接口正常返回数据[cite: 14, 15, 16]。                         |
| 40001  | 参数缺失   | 客户端缺少必填的查询或控制参数（如 `src/dst`、`signalId`、`gateId` 等）[cite: 14, 15, 16]。 |
| 40002  | 参数非法   | 传入参数取值越界或不合法（如 `phase`/`mode` 取值非法，配时超限等）[cite: 15, 16]。 |
| 40401  | 资源不存在 | 请求操作的节点、信号灯或门闸等实体在数据库或拓扑中未找到[cite: 14, 15, 16]。 |
| 40402  | 路径不连通 | 针对最短路径查询，起终点之间不存在可达路径[cite: 14]。       |

## 分页约定

*   **Top-N 查询**：部分排行接口支持通过 `limit` 参数控制最大返回条数（如 `?limit=10`）[cite: 14]。
*   **常规列表分页**：统一通过查询参数 `page`（当前页码，默认 1）和 `pageSize`（每页条数，默认 20）进行控制。返回体 `data` 中需额外包含 `total`（总条数）字段。

## 其他约定

*   **字段命名规范**：REST 接口的请求体、响应体、URL 参数强行约定采用小写驼峰（camelCase）命名（如 `signalId`、`throughputCap`）[cite: 15, 16]。
*   **数据转换隔离**：仿真引擎内部使用的下划线命名（`snake_case`）与 REST 层的驼峰命名转换，必须由后端转换层统一负责处理[cite: 15, 16]。
*   **ID 唯一来源**：节点ID (`nodeId`) 唯一来源为拓扑文件[cite: 14]；红绿灯ID (`signalId`) 和门闸ID (`gateId`) 唯一来源为后端建表维护的物理设备表[cite: 15, 16]。
