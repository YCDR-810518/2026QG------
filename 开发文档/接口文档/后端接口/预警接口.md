# 预警接口

> 对应需求：FR-22（异常检测：异常拥堵、滞留人员、门闸状态异常）、FR-23（安全预警与应急响应）

## 文档说明

本文件覆盖安全预警相关接口：预警事件查询（供前端E展示）、预警事件入库（供D直接调用）、应急响应状态更新

**数据流向**：`D（AI预测模块）→ B（后端）→ E（前端）`

## 1.预警事件查询接口

- **方法/路径**：`GET /api/v1/security/alerts`
- **功能**：查询预警事件列表（类型、位置、时间、级别等，供大屏/后台展示）
- **权限**：需登录

### 请求参数

| 参数      | 类型   | 必填 | 说明                                                             |
| :-------- | :----- | :--- | :--------------------------------------------------------------- |
| status    | string | 否   | 按状态过滤：`pending` / `resolved` / `all`（默认 `all`） |
| riskLevel | string | 否   | 按风险等级过滤：`yellow` / `red`                             |
| nodeId    | string | 否   | 按节点编码过滤                                                   |
| page      | int    | 否   | 当前页码，默认 1                                                 |
| pageSize  | int    | 否   | 每页条数，默认 20                                                |

### 请求示例

```http
GET /api/v1/security/alerts?status=pending&riskLevel=red&page=1&pageSize=10
Host: 192.168.1.114:8100
Authorization: Bearer <token>
```

### 响应参数

| 字段          | 类型   | 必填 | 说明                                      |
| :------------ | :----- | :--- | :---------------------------------------- |
| alertId       | string | 是   | 预警编号（格式：`ALT-YYYYMMDD-XXX`）    |
| nodeId        | string | 是   | 关联节点编码                              |
| nodeName      | string | 是   | 节点名称                                  |
| riskLevel     | string | 是   | 风险等级：`yellow` / `red`            |
| status        | string | 是   | 状态：`pending` / `resolved`          |
| triggerSource | string | 是   | 触发来源：固定为`ai_prediction`         |
| description   | string | 是   | 预警描述                                  |
| createdAt     | string | 是   | 创建时间（格式：`YYYY-MM-DD HH:MM:SS`） |
| resolvedAt    | string | 否   | 解决时间，未解决时为`null`              |
| actionTaken   | string | 否   | 处置措施，未解决时为`null`              |

## 2. 预警事件入库接口

- **方法/路径**：`POST /api/v1/security/alerts/create`
- **功能**：接收 D 的预警数据并写入数据库
- **权限**：需登录
- **调用方**：**D（AI预测模块）**

## 请求参数

| 参数                   | 类型   | 必填 | 说明                                                                               |
| :--------------------- | :----- | :--- | :--------------------------------------------------------------------------------- |
| event_id               | string | 否   | D 事件ID（仅用于追溯）                                                             |
| timestamp              | string | 是   | 预警时间（格式：`YYYY-MM-DDTHH:MM:SS`）                                          |
| level                  | string | 是   | 预警等级：`L1`/`L2`/`L3`（映射：`L1`→`yellow`，`L2`/`L3`→`red`） |
| type                   | string | 是   | 预警类型：`congestion`/滞留/异常等                                               |
| node_id                | string | 是   | 节点编码（必须与数据库中的`node_id` 一致）                                       |
| node_name              | string | 是   | 节点名称                                                                           |
| current_density        | float  | 否   | 当前密度                                                                           |
| threshold_density      | float  | 否   | 阈值密度                                                                           |
| predicted_duration_min | int    | 否   | 预测持续时间（分钟）                                                               |
| suggested_action       | string | 否   | 建议措施                                                                           |
| status                 | string | 否   | 状态：`active`/`resolved`（默认 `active`→`pending`）                      |

### 请求示例

```http
POST /api/v1/security/alerts/create
Content-Type: application/json
Authorization: Bearer <token>

{
    "event_id": "EVT-20260805-001",
    "timestamp": "2026-08-05T14:32:00",
    "level": "L2",
    "type": "congestion",
    "node_id": "zone_canteen",
    "node_name": "食堂",
    "current_density": 2.35,
    "threshold_density": 1.80,
    "predicted_duration_min": 8,
    "suggested_action": "门闸限流50%",
    "status": "active"
}
```

### 响应示例（成功）

```json
{
    "code": 0,
    "message": "ok",
    "data": {
        "alertId": "ALT-20260805-001",
        "status": "pending",
        "createdAt": "2026-08-05 14:32:00"
    }
}
```

### 响应示例（失败 - 节点不存在）

```json
{
    "code": 40401,
    "message": "节点不存在: zone_canteen",
    "data": {}
}
```

### 响应示例（失败 - 参数缺失）

```json
{
    "code": 40001,
    "message": "缺少必填字段: node_id",
    "data": {}
}
```

### 响应参数说明

| 字段      | 类型   | 必填 | 说明                                                 |
| :-------- | :----- | :--- | :--------------------------------------------------- |
| alertId   | string | 是   | 预警编号（后端自动生成，格式：`ALT-YYYYMMDD-XXX`） |
| status    | string | 是   | 状态：`pending`（待处理）                          |
| createdAt | string | 是   | 创建时间（格式：`YYYY-MM-DD HH:MM:SS`）            |

### 错误码

| 错误码 | 含义                                                            |
| :----- | :-------------------------------------------------------------- |
| 40001  | 缺少必填字段（`node_id`、`level`、`timestamp`、`type`） |
| 40002  | `level` 取值非法（只能为 `L1`/`L2`/`L3`）               |
| 40401  | 节点不存在（`node_id` 在数据库中未找到）                      |

## 应急响应状态接口

- **方法/路径**：`PUT /api/v1/security/alerts/{alertId}/resolve`
- **功能**：查询/更新应急响应状态，将预警事件标记为已解决，并记录处置措施
- **权限**：需登录

### 请求参数（URL Path）

| 参数    | 类型   | 必填 | 说明                              |
| :------ | :----- | :--- | :-------------------------------- |
| alertId | string | 是   | 预警编号（如 `ALT-20260805-001`） |

### 请求参数（JSON Body）

| 参数        | 类型   | 必填 | 说明                                           |
| :---------- | :----- | :--- | :--------------------------------------------- |
| actionTaken | string | 是   | 处置措施描述（如“门闸限流50%，CAV协同已启用”） |

### 请求示例

```json
PUT /api/v1/security/alerts/ALT-20260805-001/resolve
Content-Type: application/json
Authorization: Bearer <token>

{
    "actionTaken": "门闸限流50%，CAV协同已启用，密度已降至安全阈值"
}
```

### 响应示例（成功）

```json
{
    "code": 0,
    "message": "ok",
    "data": {
        "alertId": "ALT-20260805-001",
        "status": "resolved",
        "resolvedAt": "2026-08-05 17:30:00",
        "actionTaken": "门闸限流50%，CAV协同已启用，密度已降至安全阈值"
    }
}
```

### 响应示例（失败 - 预警不存在）

```json
{
    "code": 40401,
    "message": "预警不存在",
    "data": {}
}
```

### 响应示例（失败 - 预警已解决）

```json
{
    "code": 40402,
    "message": "预警已被解决",
    "data": {}
}
```

### 响应参数说明

| 字段        | 类型   | 必填 | 说明                                    |
| :---------- | :----- | :--- | :-------------------------------------- |
| alertId     | string | 是   | 预警编号                                |
| status      | string | 是   | 状态：`resolved`                        |
| resolvedAt  | string | 是   | 解决时间（格式：`YYYY-MM-DD HH:MM:SS`） |
| actionTaken | string | 是   | 处置措施描述                            |

### 错误码

| 错误码 | 含义                           |
| :----- | :----------------------------- |
| 40001  | `actionTaken` 参数缺失         |
| 40401  | 预警不存在（`alertId` 未找到） |
| 40402  | 预警已被解决（不允许重复解决） |
