# 门闸接口

> 对应需求：FR-19（动态门闸控制算法，按人流数据自动调节开关策略）

## 文档说明

本文件覆盖门闸相关接口：门闸状态查询、开闭控制、策略配置等。字段命名遵循 REST 层**小写驼峰**（`gateId` / `throughputCap`），引擎内部 snake_case → REST camelCase 转换层由 B（张紫桐）后端负责。

---

## 门闸状态查询接口

- **方法/路径**：GET /api/v1/gate/status
- **功能**：查询各门闸的当前状态（开/关、模式、实时通行速率等）
- **权限**：需登录
- **对应需求**：FR-19

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| gateId | string | 否 | 门闸编号，不传返回全部门闸 |
| nodeId | string | 否 | 按所属入口节点过滤 |

### 请求示例

```http
GET /api/v1/gate/status?nodeId=gate_north
```

### 响应示例

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "gates": [
      {
        "gateId": "G01",
        "nodeId": "gate_north",
        "mode": "restrict",
        "throughputCap": 90,
        "nLanes": 2,
        "gateStatus": 2,
        "gateFlowRate": 45.0
      }
    ]
  }
}
```

### 响应参数说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| gateId | string | 是 | 门闸编号（全园区唯一，来源：门闸表） |
| nodeId | string | 是 | 所属入口节点（引用拓扑文件 entrance 节点） |
| mode | string | 是 | 控制模式：open / restrict / close |
| throughputCap | int | 是 | 单位 tick 放行人数上限 |
| nLanes | int | 是 | 开闸数（1~max_lanes） |
| gateStatus | int | 是 | 状态码：0=关闭, 1=正常开放, 2=限流, 3=故障 |
| gateFlowRate | float | 是 | 当前通行速率（人/分钟） |

### 错误码

| 错误码 | 含义 |
|---|---|
| 40401 | 门闸不存在 |

## 门闸开闭控制接口

- **方法/路径**：POST /api/v1/gate/control
- **功能**：手动控制门闸开闭（或提交自动策略执行结果）
- **权限**：需登录
- **对应需求**：FR-19

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| gateId | string | 是 | 门闸编号 |
| mode | string | 是 | 目标模式：open / restrict / close |
| nLanes | int | 否 | 开闸数（1~max_lanes，默认当前值） |

### 请求示例

```http
POST /api/v1/gate/control
Content-Type: application/json

{
  "gateId": "G01",
  "mode": "restrict",
  "nLanes": 2
}
```

### 响应示例

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "gateId": "G01",
    "nodeId": "gate_north",
    "mode": "restrict",
    "gateStatus": 2
  }
}
```

### 响应参数说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| gateId | string | 是 | 门闸编号 |
| nodeId | string | 是 | 所属入口节点 |
| mode | string | 是 | 当前控制模式：open / restrict / close |
| gateStatus | int | 是 | 状态码：0=关闭, 1=正常开放, 2=限流, 3=故障 |

### 错误码

| 错误码 | 含义 |
|---|---|
| 40001 | gateId / mode 参数缺失 |
| 40002 | mode 取值非法 |
| 40401 | 门闸不存在 |

- **功能**：配置门闸控制策略参数（模式、放行上限、开闸数等）

- **对应需求**：FR-19

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| gateId | string | 是 | 门闸编号 |
| mode | string | 否 | 控制模式：open / restrict / close |
| throughputCap | int | 否 | 单位 tick 放行人数上限 |
| nLanes | int | 否 | 开闸数（1~max_lanes） |

### 请求示例

```http
PUT /api/v1/gate/policy
Content-Type: application/json

{
  "gateId": "G01",
  "mode": "restrict",
  "throughputCap": 90,
  "nLanes": 2
}
```

### 响应示例

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "gateId": "G01",
    "nodeId": "gate_north",
    "mode": "restrict",
    "throughputCap": 90,
    "nLanes": 2
  }
}
```

### 响应参数说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| gateId | string | 是 | 门闸编号 |
| nodeId | string | 是 | 所属入口节点 |
| mode | string | 是 | 控制模式：open / restrict / close |
| throughputCap | int | 是 | 单位 tick 放行人数上限 |
| nLanes | int | 是 | 开闸数（1~max_lanes） |

### 错误码

| 错误码 | 含义 |
|---|---|
| 40001 | gateId 参数缺失 |
| 40002 | 策略参数非法（如 mode 取值非法、nLanes 超出 1~max_lanes） |
| 40401 | 门闸不存在 |

## 字段约定汇总

> 引擎内部 snake_case → REST 小写驼峰，转换层由 B（张紫桐）后端负责。

| 内部字段 | REST 字段 |
|---|---|
| `gate_id` | `gateId` |
| `throughput_cap` | `throughputCap` |
| `n_lanes` | `nLanes` |
| `gate_status` | `gateStatus` |
| `gate_flow_rate` | `gateFlowRate` |

> **唯一来源**：`gate_id` → 门闸表（B 建表维护）；`node_id` → A 拓扑 entrance 节点。
