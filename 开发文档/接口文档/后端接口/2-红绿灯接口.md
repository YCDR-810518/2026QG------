# 红绿灯接口

> 对应需求：FR-19 扩展（红绿灯动态调控，按人流/车流自动调节信号相位）

## 文档说明

本文件覆盖红绿灯相关接口：信号灯状态查询、灯色控制、策略配置等。字段命名遵循 REST 层**小写驼峰**（`signalId` / `cycleTime`），引擎内部 snake_case → REST camelCase 转换层由 B（张紫桐）后端负责。

---

## 信号灯状态查询接口

- **方法/路径**：GET /api/v1/signal/status
- **功能**：查询各路口信号灯的当前状态（灯色、周期、实时通行速率等）
- **权限**：需登录
- **对应需求**：FR-19

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| signalId | string | 否 | 红绿灯编号，不传返回全部信号灯 |
| nodeId | string | 否 | 按所属路口节点过滤 |

### 请求示例

```http
GET /api/v1/signal/status?nodeId=cross_1
```

### 响应示例

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "signals": [
      {
        "signalId": "S01",
        "nodeId": "cross_1",
        "mode": "adaptive",
        "phase": "green",
        "cycleTime": 60,
        "greenTime": 30,
        "yellowTime": 3,
        "redTime": 27,
        "offset": 0,
        "throughputCap": 90,
        "nPhases": 2,
        "signalStatus": 1,
        "signalFlowRate": 45.0
      }
    ]
  }
}
```

### 响应参数说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| signalId | string | 是 | 红绿灯编号（全园区唯一，来源：红绿灯表） |
| nodeId | string | 是 | 所属路口节点（引用拓扑文件 cross_road 节点） |
| mode | string | 是 | 控制模式：fixed / adaptive / flash |
| phase | string | 是 | 当前相位（灯色）：green / yellow / red / off |
| cycleTime | int | 是 | 信号周期时长（秒） |
| greenTime | int | 是 | 绿灯时长（秒） |
| yellowTime | int | 是 | 黄灯时长（秒） |
| redTime | int | 是 | 红灯时长（秒） |
| offset | int | 是 | 相位起始偏移（秒，绿波带协调用） |
| throughputCap | int | 是 | 单位 tick 放行人数上限 |
| nPhases | int | 是 | 相位数（1~4） |
| signalStatus | int | 是 | 状态码：0=熄灭/故障, 1=正常运行, 2=黄闪, 3=故障 |
| signalFlowRate | float | 是 | 当前通行速率（人/分钟） |

### 错误码

| 错误码 | 含义 |
|---|---|
| 40401 | 信号灯不存在 |

## 信号灯控制接口

- **方法/路径**：POST /api/v1/signal/control
- **功能**：手动切换灯色（或提交自适应策略执行结果）
- **权限**：需登录
- **对应需求**：FR-19

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| signalId | string | 是 | 红绿灯编号 |
| phase | string | 是 | 目标灯色：green / yellow / red / off |
| mode | string | 否 | 切回的控制模式：fixed / adaptive / flash（默认 adaptive） |

### 请求示例

```http
POST /api/v1/signal/control
Content-Type: application/json

{
  "signalId": "S01",
  "phase": "red"
}
```

### 响应示例

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "signalId": "S01",
    "nodeId": "cross_1",
    "mode": "adaptive",
    "phase": "red",
    "signalStatus": 1
  }
}
```

### 响应参数说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| signalId | string | 是 | 红绿灯编号 |
| nodeId | string | 是 | 所属路口节点 |
| mode | string | 是 | 当前控制模式：fixed / adaptive / flash |
| phase | string | 是 | 当前灯色：green / yellow / red / off |
| signalStatus | int | 是 | 状态码：0=熄灭/故障, 1=正常运行, 2=黄闪, 3=故障 |

### 错误码

| 错误码 | 含义 |
|---|---|
| 40001 | signalId / phase 参数缺失 |
| 40002 | phase 取值非法 |
| 40401 | 信号灯不存在 |

## 信号灯策略配置接口

- **方法/路径**：PUT /api/v1/signal/policy
- **功能**：配置信号控制策略参数（周期、各相位时长、控制模式等）
- **权限**：需登录
- **对应需求**：FR-19

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| signalId | string | 是 | 红绿灯编号 |
| mode | string | 否 | 控制模式：fixed / adaptive / flash |
| cycleTime | int | 否 | 信号周期时长（秒） |
| greenTime | int | 否 | 绿灯时长（秒） |
| yellowTime | int | 否 | 黄灯时长（秒） |
| redTime | int | 否 | 红灯时长（秒） |
| offset | int | 否 | 相位起始偏移（秒，绿波带协调用） |
| throughputCap | int | 否 | 单位 tick 放行人数上限 |
| nPhases | int | 否 | 相位数（1~4） |

### 请求示例

```http
PUT /api/v1/signal/policy
Content-Type: application/json

{
  "signalId": "S01",
  "mode": "fixed",
  "cycleTime": 90,
  "greenTime": 45,
  "yellowTime": 5,
  "redTime": 40
}
```

### 响应示例

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "signalId": "S01",
    "nodeId": "cross_1",
    "mode": "fixed",
    "cycleTime": 90,
    "greenTime": 45,
    "yellowTime": 5,
    "redTime": 40,
    "offset": 0,
    "throughputCap": 90,
    "nPhases": 2
  }
}
```

### 响应参数说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| signalId | string | 是 | 红绿灯编号 |
| nodeId | string | 是 | 所属路口节点 |
| mode | string | 是 | 控制模式：fixed / adaptive / flash |
| cycleTime | int | 是 | 信号周期时长（秒） |
| greenTime | int | 是 | 绿灯时长（秒） |
| yellowTime | int | 是 | 黄灯时长（秒） |
| redTime | int | 是 | 红灯时长（秒） |
| offset | int | 是 | 相位起始偏移（秒，绿波带协调用） |
| throughputCap | int | 是 | 单位 tick 放行人数上限 |
| nPhases | int | 是 | 相位数（1~4） |

### 错误码

| 错误码 | 含义 |
|---|---|
| 40001 | signalId 参数缺失 |
| 40002 | 时长参数非法（如 greenTime + yellowTime + redTime > cycleTime、nPhases 超出 1~4） |
| 40401 | 信号灯不存在 |

## 字段约定汇总

> 引擎内部 snake_case → REST 小写驼峰，转换层由 B（张紫桐）后端负责。

| 内部字段 | REST 字段 |
|---|---|
| `signal_id` | `signalId` |
| `cycle_time` | `cycleTime` |
| `green_time` | `greenTime` |
| `yellow_time` | `yellowTime` |
| `red_time` | `redTime` |
| `throughput_cap` | `throughputCap` |
| `n_phases` | `nPhases` |
| `signal_status` | `signalStatus` |
| `signal_flow_rate` | `signalFlowRate` |

> **唯一来源**：`signal_id` → 红绿灯表（B 建表维护）；`node_id` → A 拓扑 cross_road 节点。
