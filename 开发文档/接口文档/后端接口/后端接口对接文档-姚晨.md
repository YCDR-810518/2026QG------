## 三、接口详细定义

### 3.1 ① 节点监控接口

```
GET /api/v1/network/nodes
```

#### 响应字段

| 字段 | 类型 | 必填 | 含义 | 数据来源 |
|------|------|------|------|----------|
| `nodeId` | str | 是 | 节点编码（全园区唯一） | A 拓扑 |
| `nodeName` | str | 是 | 节点名称（如"食堂"） | A 拓扑 |
| `x` | float | 是 | 地图 X 坐标 | A 拓扑 |
| `y` | float | 是 | 地图 Y 坐标 | A 拓扑 |
| `type` | str | 是 | 节点类型：entrance / cross_road / divergence / hotspot / stop | A 拓扑 |
| `gateId` | str | 否 | 门闸编号（仅 entrance 节点有值） | A 拓扑 → 引用 B 门闸表 |
| `people` | int | 否 | 实时人数 | F 仿真引擎 |
| `density` | float | 否 | 实时密度（0~1） | F 仿真引擎 |
| `level` | str | 否 | 实时拥挤等级：low / medium / high / critical | F 仿真引擎 |

#### 响应 JSON 样例

```json
{
  "code": 0,
  "message": "ok",
  "data": [
    {
      "nodeId": "zone_canteen",
      "nodeName": "食堂",
      "x": 460,
      "y": 180,
      "type": "hotspot",
      "gateId": "",
      "people": 1200,
      "density": 0.8,
      "level": "high"
    }
  ]
}
```

#### Django Model 字段映射

| REST 字段 | Model 字段 | Model 类型 | 约束 |
|-----------|-----------|-----------|------|
| `nodeId` | `node_id` | `CharField(max_length=64)` | `primary_key=True` |
| `nodeName` | `node_name` | `CharField(max_length=128)` | |
| `x` | `x` | `FloatField()` | |
| `y` | `y` | `FloatField()` | |
| `type` | `node_type` | `CharField(max_length=32)` | choices 见下方 |
| `gateId` | `gate_id` | `CharField(max_length=32)` | `blank=True, default=""` |

> 注意：`people`、`density`、`level` 是 F 仿真引擎的**动态数据**，不存储在 A 的拓扑表中，由 F 通过单独的实时数据接口写入。

### 3.3 ③ 最短路径查询接口

```
GET /api/v1/network/shortest-path?src={nodeId}&dst={nodeId}
```

#### 请求参数

| 参数 | 类型 | 必填 | 含义 |
|------|------|------|------|
| `src` | str | 是 | 起点 nodeId |
| `dst` | str | 是 | 终点 nodeId |

#### 响应字段

| 字段 | 类型 | 含义 |
|------|------|------|
| `src` | str | 起点 nodeId（回显） |
| `dst` | str | 终点 nodeId（回显） |
| `path` | str[] | 途径节点列表（含起终点） |
| `travelTime` | float | 通行时间（分钟） |

#### 响应 JSON 样例

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "src": "gate_north",
    "dst": "zone_canteen",
    "path": ["gate_north", "cross_1", "diverg_1", "cross_4", "zone_canteen"],
    "travelTime": 6.2
  }
}
```

#### 错误码

| 错误码 | 含义 |
|--------|------|
| 40001 | src 或 dst 参数缺失 |
| 40004 | nodeId 不存在 |
| 40005 | 两点间无可达路径 |

## 五、B 的实现建议

### 5.1 Django Model（仅节点静态信息表）

```python
# api/models.py

class NetworkNode(models.Model):
    node_id = models.CharField(max_length=64, primary_key=True)
    node_name = models.CharField(max_length=128)
    x = models.FloatField()
    y = models.FloatField()
    node_type = models.CharField(max_length=32, choices=[
        ('entrance', '入口'),
        ('cross_road', '十字路口'),
        ('divergence', '分歧点'),
        ('hotspot', '热点'),
        ('stop', '上下车点'),
    ])
    gate_id = models.CharField(max_length=32, blank=True, default='')

    class Meta:
        db_table = 'network_nodes'
```

### 5.2 DRF Serializer

```python
# api/serializers.py

class NetworkNodeSerializer(serializers.ModelSerializer):
    nodeId = serializers.CharField(source='node_id')
    nodeName = serializers.CharField(source='node_name')
    nodeType = serializers.CharField(source='node_type')
    gateId = serializers.CharField(source='gate_id')

    class Meta:
        model = NetworkNode
        fields = ['nodeId', 'nodeName', 'x', 'y', 'nodeType', 'gateId']
```
