# 交通网络接口

> 对应需求：FR-06（拓扑网络构建）、FR-07（最短路径）、FR-08（PageRank/中介中心性）、FR-09（AttractRank 热点分析）
>
> 实现来源：A 的 `DjShortCut.py`（TrafficNetwork / ShortestPathFinder）+ `macro_topo.py`（TrafficNetworkAnalyzer）

## 文档说明

本文件覆盖交通网络相关接口：节点监控、路段（边）信息、路段热度指标、最短路径查询、热点区域分析等。
字段命名遵循 REST 层**小写驼峰**（`nodeId` / `heatScore`），引擎内部 snake_case → REST camelCase 转换层由 B（张紫桐）后端负责。

---

## 节点监控接口

- **方法/路径**：GET /api/v1/network/nodes
- **功能**：查询交通网络各节点的实时状态（位置、人流量、拥挤度等）
- **权限**：需登录
- **对应需求**：FR-06

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| nodeId | string | 否 | 节点编码，不传返回全部节点 |
| type | string | 否 | 按节点类型过滤：entrance / cross_road / divergence / hotspot / stop |

### 请求示例

```http
GET /api/v1/network/nodes?type=hotspot
```

### 响应示例

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "nodes": [
      {
        "nodeId": "zone_canteen",
        "nodeName": "食堂",
        "x": 460.0,
        "y": 180.0,
        "type": "hotspot",
        "people": 1200,
        "density": 0.8,
        "level": "high",
        "gateId": "G01",
        "signalId": "S01",
        "edgeIds": ["E05", "E14"]
      }
    ]
  }
}
```

### 响应参数说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| nodeId | string | 是 | 节点编码（全园区唯一，来源：拓扑文件） |
| nodeName | string | 是 | 节点名称（如"食堂"） |
| x / y | float | 是 | 地图坐标 |
| type | string | 是 | 节点类型：entrance / cross_road / divergence / hotspot / stop |
| people | int | 是 | 实时人数（来自仿真引擎，后端合并） |
| density | float | 是 | 实时密度 |
| level | string | 是 | 拥挤等级：low / medium / high / critical |
| gateId | string | 否 | 门闸编号，仅 entrance 节点返回，无门闸节点不返回该字段 |
| signalId | string | 否 | 红绿灯编号，仅配置了信号灯的节点返回，未配置不返回该字段 |
| edgeIds | string[] | 否 | 该节点关联的边编号列表 |

### 错误码

| 错误码 | 含义 |
|---|---|
| 40401 | 节点不存在 |

## 路段热度指标接口

- **方法/路径**：GET /api/v1/network/hotness
- **功能**：查询各节点的热度指标（PageRank、中介中心性、综合热度分、排名），对接 A 的 `TrafficNetworkAnalyzer.transform()` 输出
- **权限**：需登录
- **对应需求**：FR-08
- **实现模块**：`macro_topo.py` → `TrafficNetworkAnalyzer`

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| nodeId | string | 否 | 节点编码，不传返回全部节点热度 |
| limit | int | 否 | 仅返回热度排行前 N 名（如 10） |

### 请求示例

```http
GET /api/v1/network/hotness?limit=10
```

### 响应示例

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "items": [
      {
        "nodeId": "zone_canteen",
        "pagerank": 0.21,
        "betweenness": 156.4,
        "heatScore": 92.5,
        "rank": 1
      }
    ]
  }
}
```

### 响应参数说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| nodeId | string | 是 | 节点编码 |
| pagerank | float | 是 | PageRank 得分（0~1） |
| betweenness | float | 是 | 中介中心性 |
| heatScore | float | 是 | 综合热度分（0~100，算法归一化） |
| rank | int | 是 | 热度排行（1 = 最热） |

### 错误码

| 错误码 | 含义 |
|---|---|
| 40401 | 节点不存在 |

## 最短路径查询接口

- **方法/路径**：GET /api/v1/network/shortest-path
- **功能**：查询两点间最短路径，支持闸机/红绿灯状态影响（对接 A 的 Dijkstra 算法）
- **权限**：需登录
- **对应需求**：FR-07
- **实现模块**：`DjShortCut.py` → `ShortestPathFinder.predict()`

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| src | string | 是 | 起点 nodeId |
| dst | string | 是 | 终点 nodeId |

### 请求示例

```http
GET /api/v1/network/shortest-path?src=gate_north&dst=zone_canteen
```

### 响应示例

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "src": "gate_north",
    "dst": "zone_canteen",
    "path": ["gate_north", "cross_1", "diverg_1", "cross_4", "zone_canteen"],
    "travelTime": 6.2
  }
}
```

### 响应参数说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| src | string | 是 | 起点 nodeId |
| dst | string | 是 | 终点 nodeId |
| path | string[] | 是 | 途径节点列表（含起终点） |
| travelTime | float | 是 | 通行时间（分钟，边权值之和） |

### 错误码

| 错误码 | 含义 |
|---|---|
| 40001 | src/dst 参数缺失 |
| 40401 | 起终点节点不存在 |
| 40402 | 起终点不连通 |

## 热点区域分析接口

- **方法/路径**：GET /api/v1/network/hotspots
- **功能**：查询热点区域分析结果（空间聚类 + 区域吸引度评分）
- **权限**：需登录
- **对应需求**：FR-09
- **实现模块**：`macro_attractrank.py` → `AttractRankAnalyzer.transform()`

### 请求参数

无（返回全部热点区域）

### 请求示例

```http
GET /api/v1/network/hotspots
```

### 响应示例

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "hotspots": [
      {
        "region": "canteen_area",
        "nodeIds": ["zone_canteen", "cross_4"],
        "attractScore": 88.0
      }
    ]
  }
}
```

### 响应参数说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| region | string | 是 | 热点区域标识 |
| nodeIds | string[] | 是 | 该区域覆盖的节点 |
| attractScore | float | 是 | AttractRank 吸引度得分 |

### 错误码

无

## 路段（边）信息查询接口

- **方法/路径**：GET /api/v1/network/edge
- **功能**：查询路段（边）的静态/基础信息（关联节点、长度、权重、容量等）
- **权限**：需登录
- **对应需求**：FR-06

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| edgeId | string | 否 | 边编号，不传返回全部路段 |

### 请求示例

```http
GET /api/v1/network/edge?edgeId=E05
```

### 响应示例

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "edges": [
      {
        "edgeId": "E05",
        "nodes": ["cross_2", "zone_canteen"],
        "length": 120.0,
        "weight": 1.2,
        "capacity": 80
      }
    ]
  }
}
```

### 响应参数说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| edgeId | string | 是 | 边编号（全园区唯一，来源：拓扑文件） |
| nodes | string[] | 是 | 边两端节点编码（起点、终点） |
| length | float | 是 | 边长度 |
| weight | float | 是 | 边权重 |
| capacity | int | 是 | 边容量 |

### 错误码

| 错误码 | 含义 |
|---|---|
| 40401 | 路段不存在 |
