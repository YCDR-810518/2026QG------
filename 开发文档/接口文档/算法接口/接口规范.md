# 算法接口规范

> 对应需求：FR-10（统一算法接口规范，遵循 sklearn 风格）

## 总约定

算法模块对外接口统一遵循 sklearn 风格，详细规范见《变量及接口命名规范.md》，要点摘录如下。

## 核心方法签名

| 方法 | 签名 | 约定 |
|---|---|---|
| fit | fit(X, y=None) | 训练/学习，**必须返回 self** |
| predict | predict(X) | 预测，返回数组（不返回 self） |
| transform | transform(X) | 数据变换，返回数组 |
| fit_transform | fit_transform(X, y=None) | = fit 后 transform |
| fit_predict | fit_predict(X, y=None) | = fit 后 predict（聚类/异常检测用） |
| predict_proba | predict_proba(X) | 概率输出（如有） |
| score | score(X, y=None) | 模型评估得分 |
| get_params | get_params(deep=True) | 获取超参数 |
| set_params | set_params(**params) | 设置超参数，返回 self |
| partial_fit | partial_fit(X, y=None, classes=None) | 增量训练（可选） |

## 命名约定

- 构造参数：`__init__` 参数原样存为同名属性，**不加下划线**
- 数据学到的属性：加**尾下划线**（`n_features_in_`、`anomaly_scores_` 等）
- 数据约定：`X` 为样本×特征二维数组 `(n_samples, n_features)`，`y` 为一维目标数组
- 数值计算返回 `numpy.ndarray`
