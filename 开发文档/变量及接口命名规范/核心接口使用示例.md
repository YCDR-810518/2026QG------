## 一、总体使用节奏

sklearn 风格接口的使用遵循固定节奏：

```
创建（只传超参数）→ fit（学习，返回 self）→ 保存模型（.ckpt，保证可复现）
→ predict / transform（对外服务）→ score（评估）→ get_params / set_params（调参管理）
```

核心心智模型：**`fit` 让模型学东西，学到的存在带下划线 `_` 的属性里**（如 `model.n_features_in_`、`detector.anomaly_scores_`）；`predict/transform` 只读不改。

## 二、训练类方法：fit / fit_transform / fit_predict / partial_fit

```python
from models.density import DensityPredictor

# 1. 创建：只传超参数，__init__ 不做任何计算
model = DensityPredictor(n_layers=3, lr=1e-3)

# 2. fit：训练，接收数据，返回 self（可链式调用）
model.fit(X_train, y_train)
model = DensityPredictor(n_layers=3).fit(X_train, y_train)   # 等价写法

# 3. fit_transform：fit 和 transform 经常一起用时一次性完成
scaler = DpNoiseScaler(epsilon=1.0)
X_noisy = scaler.fit_transform(vehicle_paths)    # 先学噪声分布，再一次性加噪

# 4. fit_predict：无标签场景（聚类/异常检测），训练+打标签一步完成
detector = CongestionDetector(threshold=0.8)
labels = detector.fit_predict(X)                 # 等价于 fit(X) 再 predict(X)

# 5. partial_fit：数据量大/在线场景，分批增量训练，每批都更新模型
for batch in data_batches:
    model.partial_fit(batch_X, batch_y)
```

## 三、预测/变换类方法：predict / transform / predict_proba / score

```python
# predict：用训练好的模型对新数据做预测，返回数组，不修改模型
future_density = model.predict(X_next_10min)

# predict_proba：需要概率输出（如准入决策）时使用
p_allow = policy.predict_proba(vehicle_request)  # 返回如 0.92 的概率值

# transform：数据变换类算法（DP 加噪、归一化），输入输出都是特征矩阵（必须先 fit 过）
noisy = DpNoiseScaler(epsilon=1.0).transform(paths)

# score：统一评估入口，内部计算评估指标
accuracy = model.score(X_test, y_test)
```

## 四、参数管理类方法：get_params / set_params

```python
# get_params：查看当前超参数（调试、存档用）
print(model.get_params())     # {'n_layers': 3, 'lr': 0.001, ...}

# set_params：不改对象直接换参数后重训，返回 self 可链式
model.set_params(lr=1e-4).fit(X_train, y_train)
```

> 作用：`get_params/set_params` 是 sklearn 接口的"身份证"。有了它，超参数搜索与模型存档（配合 `model_config.yaml`）都能用统一代码处理，是检查标准五"接口统一"的关键组成。

# —— 成员C：车辆准入 ——
policy = VehicleAccessPolicy().fit(density_stats)

# —— 成员D：密度预测（内部 MindSpore）——
predictor = DensityPredictor(n_layers=3, lr=1e-3).fit(X_train, y_train)
pred = predictor.predict(X_next_10min)

# —— 成员D：异常检测 ——
detector = CongestionDetector(threshold=0.8).fit_predict(X)
print(detector.anomaly_scores_)

# —— 成员F：门闸策略 ——
gate = GatePolicyController(window_size=10).fit(gate_history)
policy = gate.predict(density_now)                           # 开/关策略

# —— 成员F：宏微联合调控 ——
