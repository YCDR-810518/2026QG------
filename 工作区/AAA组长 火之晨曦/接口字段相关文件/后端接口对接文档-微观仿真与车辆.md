## 三、接口详细定义

### 3.1 ① 车辆准入决策接口

```
POST /api/v1/vehicle/access
```

> B 的 View 收到请求后，调用 C 的 `VehicleAccessPolicy.predict(vehicle_request)` 得到决策结果并返回。

#### 请求体

| 字段 | 类型 | 必填 | 含义 | 约束 |
|------|------|------|------|------|
| `vehicleId` | str | 是 | 车辆唯一标识（车牌或虚拟 ID） | |
| `type` | str | 是 | 车辆类型 | visitor / staff / emergency |
| `entryNode` | str | 是 | 申请驶入的入口节点 | 必须是 A 拓扑中的 entrance 节点 |
| `targetNode` | str | 是 | 目标节点 | 必须是 A 拓扑中的节点 |

```json
{
  "vehicleId": "粤B·12345",
  "type": "visitor",
  "entryNode": "gate_north",
  "targetNode": "zone_canteen"
}
```

#### 响应体

| 字段 | 类型 | 含义 |
|------|------|------|
| `isAllowed` | bool | 是否允许驶入 |
| `reason` | str | 拒绝原因（如"区域重度拥堵"），允许则为空 |
| `cavMode` | bool | 是否开启车联网协同（CAV 实验组） |
| `plannedPath` | str[] | 微观规划路径（节点 ID 数组，调用 A 最短路径生成） |

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "isAllowed": true,
    "reason": "",
    "cavMode": true,
    "plannedPath": ["gate_north", "cross_1", "diverg_1", "zone_canteen"]
  }
}
```

#### 拒绝场景响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "isAllowed": false,
    "reason": "目标区域食堂当前重度拥堵，建议 15 分钟后重新申请",
    "cavMode": false,
    "plannedPath": []
  }
}
```

#### 错误码

| 错误码 | 含义 |
|--------|------|
| 40006 | vehicleId 缺失 |
| 40007 | entryNode 不存在于拓扑中 |
| 40008 | targetNode 不存在于拓扑中 |
| 40009 | entryNode 非 entrance 类型节点 |

### 3.4 ④ 差分隐私轨迹上传接口

```
POST /api/v1/vehicle/trajectory
```

> 车辆在园区内行驶的真实坐标，经 C 的 `DpNoiseScaler.transform()` 加噪后上传到 B 的数据库。前端 E 展示的是加噪后的轨迹，保护真实路径隐私。

#### 请求体

| 字段 | 类型 | 必填 | 含义 |
|------|------|------|------|
| `vehicleId` | str | 是 | 脱敏后的车辆 ID（如哈希值） |
| `timestamp` | int | 是 | Unix 时间戳（秒） |
| `dpX` | float | 是 | 加噪后的 X 坐标（Laplace 噪声偏移） |
| `dpY` | float | 是 | 加噪后的 Y 坐标（Laplace 噪声偏移） |
| `nodeId` | str | 否 | 当前所在节点（用于路段关联） |

```json
{
  "vehicleId": "hash_8f9a2b",
  "timestamp": 1691452800,
  "dpX": 201.45,
  "dpY": 102.12,
  "nodeId": "cross_1"
}
```

> 说明：真实坐标在 (200, 100)，`DpNoiseScaler` 加入 Laplace 噪声后产生偏移，保护隐私的同时不影响宏观分析。

#### 响应体

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "recordId": 1001,
    "uploaded": true
  }
}
```

### 3.5 ⑤ CAV 提速量化对比接口

```
GET /api/v1/vehicle/cav-comparison
```

> B 的 View 调用 C 的 `CavSimulator.predict(horizon)` 获取对比数据，供 E 大屏展示 CAV 提速效果。

#### 响应字段

| 字段 | 类型 | 含义 |
|------|------|------|
| `scenarioId` | str | 仿真场景标识 |
| `totalVehicles` | int | 场景中车辆总数 |
| `noCav` | object | 无 CAV 对照组指标 |
| `noCav.avgTravelTime` | float | 平均通行时间（分钟） |
| `noCav.throughput` | int | 道路吞吐量（辆/小时） |
| `noCav.mergeRate` | float | 汇合点通过率（0~1） |
| `withCav` | object | 有 CAV 实验组指标 |
| `withCav.avgTravelTime` | float | 平均通行时间（分钟） |
| `withCav.throughput` | int | 道路吞吐量（辆/小时） |
| `withCav.mergeRate` | float | 汇合点通过率（0~1） |
| `efficiencyGain` | float | 通行效率提升百分比 |

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "scenarioId": "peak_hour_3000",
    "totalVehicles": 200,
    "noCav": {
      "avgTravelTime": 8.5,
      "throughput": 180,
      "mergeRate": 0.72
    },
    "withCav": {
      "avgTravelTime": 6.2,
      "throughput": 240,
      "mergeRate": 0.91
    },
    "efficiencyGain": 27.1
  }
}
```

#### 查询参数（可选）

| 参数 | 类型 | 必填 | 含义 | 默认值 |
|------|------|------|------|--------|
| `scenarioId` | str | 否 | 指定场景 | 最新场景 |
| `horizon` | int | 否 | 仿真时长（tick 数） | 100 |

## 五、B 的实现建议

### 5.1 准入决策 View

```python
# api/views.py
from algo_micro import VehicleAccessPolicy

class VehicleAccessView(APIView):
    def post(self, request):
        vehicle_id = request.data.get('vehicleId')
        vehicle_type = request.data.get('type')
        entry_node = request.data.get('entryNode')
        target_node = request.data.get('targetNode')

        # 调用 C 的算法
        policy = VehicleAccessPolicy()
        policy.fit(density_data)   # 从数据库/缓存获取密度数据
        result = policy.predict({
            'vehicle_id': vehicle_id,
            'type': vehicle_type,
            'entry_node': entry_node,
            'target_node': target_node,
        })

        # 入库
        VehicleAccessRecord.objects.create(
            vehicle_id=vehicle_id,
            vehicle_type=vehicle_type,
            entry_node=entry_node,
            target_node=target_node,
            is_allowed=result['is_allowed'],
            reason=result.get('reason', ''),
            cav_mode=result.get('cav_mode', False),
            planned_path=result.get('planned_path', []),
            status='allowed' if result['is_allowed'] else 'denied',
        )

        return Response(result)
```

## 六、字段唯一来源清单

| 字段 | 唯一来源 | 责任人 |
|------|---------|--------|
| `vehicleId` / `type` | 前端请求 / C 仿真生成 | **E（廖思颖）/ C（陈思敏）** |
| `entryNode` / `targetNode` | A 拓扑 node_id | **A（姚晨）** |
| `isAllowed` / `reason` / `cavMode` | C `VehicleAccessPolicy` | **C（陈思敏）** |
| `plannedPath` | A 最短路径 → C 微观调整 | **A（姚晨）→ C（陈思敏）** |
| `dpX` / `dpY` | C `DpNoiseScaler` 加噪 | **C（陈思敏）** |
| `avgTravelTime` / `throughput` / `mergeRate` | C `CavSimulator` | **C（陈思敏）** |
| `efficiencyGain` | C 量化计算 | **C（陈思敏）** |

## 七、数据流向

```
E（前端）
  │
  ├── POST /access → B（Django）→ C（VehicleAccessPolicy.predict）
  │                                 │
  │                                 ├─ 调用 A（ShortestPathFinder）→ 宏观路径
  │                                 └─ 调用 D（DensityPredictor）→ 未来密度预测
  │
  ├── GET /cav-comparison → B → C（CavSimulator.predict）
  │
  └── POST /trajectory → B（入库）← C（DpNoiseScaler.transform）→ 加噪后上传
```
