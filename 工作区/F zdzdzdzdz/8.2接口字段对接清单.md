## 一、给 B（张紫桐 · 后端/数据库）——核心交付

### 1.1 实时人流密度字段（F→B，主交付，对应设计文档 §3.5）

| 字段（引擎内 snake_case） | 类型 | 含义 | 真实园区场景 |
|---|---|---|---|
| tick | int | 第几秒（tick 序号=模拟秒） | 系统心跳计数 |
| timestamp | str | 模拟时间 HH:MM:SS | 大屏右上角时钟 |
| nodeId | str | 节点编码（**与 A 拓扑完全一致**） | 园区某片区域编号（如 zone_canteen） |
| people | int | 该节点区域内当前人数 | 大屏每个区的红点人数 |
| vehicles | int | 该节点区域内当前车辆数 | 园区内车流统计 |
| density | float | 综合密度 = people / 区域容量（0~1+） | 热力图颜色浓度 |
| level | str | 等级：low / medium / high / critical | 大屏红黄绿阈值 |
| gateId | str |  | 门闸编号 |

**带去冻结的 JSON 样例**：

```json
{
  "tick": 3600,
  "timestamp": "10:00:00",
  "nodeId": "zone_canteen",
  "people": 1200,
  "vehicles": 15,
  "density": 0.8,
  "level": "high",
  "gateId": "G01"
}
```

### 1.2 门闸策略字段（F→B，FR-19 输出，B 门闸状态表/策略接口用）

| 字段 | 类型 | 含义 | 真实园区场景 |
|---|---|---|---|
| gateId | str | 门闸编号 | 北门闸机号 |
| mode | str | open / restricted / closed | 全开 / 限流 / 关闭 |
| throughputCap | int | 单位 tick 放行人数上限 | 每分钟放几个人进 |
| nLanes | int | 开闸数（1~max_lanes） | 开几道闸机 |

### 1.3 从 B 接收（只确认，不产字段）

- 统一响应结构 `{code, message, data}`
- 认证 token（Header: `Authorization: Bearer <token>`）
- REST 字段命名：**小写驼峰**（`nodeId` / `throughputCap`）
- 时间格式、分页约定

## 二、与 A（姚晨 · 宏观算法/PM）——双向对齐（协作3 伏笔）

| 方向 | 字段 | 含义 | 真实园区场景 |
|---|---|---|---|
| A→F | nodeId / x / y / type | 节点编号 / 坐标 / 类型（十字路口、分歧点、热点上下车区） | 园区电子地图路口与点位 |
| A→F | edge: from / to / weight / capacity | 边（路段）及权值（长度/拥堵度） | 道路段及通行时间 |
| F→A | 全节点时序密度（tick / nodeId / density） | 引擎每 tick 密度序列 | A 算 PageRank/中介中心性验证热点 |

> **关键**：`node_id` 编码以 A 的拓扑为唯一来源，F 引擎加载同一份拓扑文件。此点必须钉死。

## 三、与 C（陈思敏 · 微观/CAV）——双向对齐（协作8 伏笔）

| 方向 | 字段 | 含义 | 真实园区场景 |
|---|---|---|---|
| F→C | densityStats（各节点 people / vehicles / density） | C 准入算法输入 | 车到门口，系统查园区挤不挤 |
| F→C | 车辆实体字段：id / srcNode / dstNode / birthTick / isInternal | 车辆进出计划 | 外来车/内部车清单 |
| C→F | 准入决策：vehicleId / decision(allow/reject/limitRoute) / route | 放行 / 拒入 / 限制路线 | 门口道闸起落 + 引导路线 |

## 四、给 D（李世涵 · AI 密度预测）——先对齐格式，8.3 正式交付（协作2）

| 字段 | 类型 | 含义 | 真实园区场景 |
|---|---|---|---|
| timestamp | datetime | 时间 | 预测曲线横轴 |
| nodeId | int/str | 区域 | 预测哪个区 |
| people / vehicles / density | float | 各区域历史密度 | D 训练"密度怎么随时间变" |
| vehicleCount             | int      | 该节点当前车辆数                             |                          |
| gateStatus | int | 门闸状态码(0=关闭,1=正常开放,2=限流,3=故障） |  |
| gateFlowRate | float | 门闸当前通行速率(人/分钟) |  |
| level | int | 密度等级（可选辅助标签） | 分级标签 |

> D 的 `DensityPredictor.fit(X, y)`：X = 历史时序特征，y = 未来密度。
