# 首版数据集格式说明（成员 F → 成员 D，协作 2）

> 交付时间：2026-08-03 ｜ 规模：4000 人 / 300 车（首版，正式 8000 压测时另出）
> 生成器：`simulation/flow_data_generator.py`（sklearn 风格 `fit/generate/sample`）
> 拓扑：`data/sample_topology.json`（占位样例，A 交付 `topology.json` 后切换）

## 一、目录与文件

```
data/
├── people.csv          人员流入计划（kind=0）
├── vehicles.csv        车辆流入计划（kind=1）
├── density_series.csv  各节点密度时序（1 分钟采样，供 DensityPredictor 训练）
└── ultra_peak/
    ├── people.csv
    ├── vehicles.csv
    └── density_series.csv   # 超高峰拥塞场景，含 critical 等级样本
```

## 二、字段定义

### people.csv
| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 实体唯一 ID |
| birth_tick | int | 出生 tick（1 tick = 1 秒，06:00 起） |
| src_node | str | 起点节点编码（入口/门闸，与拓扑一致） |
| dst_node | str | 终点节点编码（热点区域） |
| kind | int | 恒为 0（行人） |

### vehicles.csv
| 字段 | 类型 | 说明 |
|---|---|---|
| id / birth_tick / src_node / dst_node | 同 people | — |
| kind | int | 恒为 1（车辆） |
| is_internal | int | 0=外来车，1=园区内部车 |

### density_series.csv（每 60 tick 一行 × 每节点）
| 字段 | 类型 | 说明 |
|---|---|---|
| tick | int | tick 序号（= 模拟秒） |
| timestamp | str | 模拟时间 HH:MM:SS |
| node_id | str | 节点编码（与拓扑一致） |
| people | int | 该节点当前人数 |
| vehicles | int | 该节点当前车辆数 |
| density | float | 综合密度 = people / 节点容量（0~1+） |
| level | str | low / medium / high / critical |
| gate_status | int | 门闸状态（0=关闭, 1=正常开放, 2=限流） |
| gate_flow_rate | float | 门闸通行速率（人/分钟） |

## 三、说明与约定

- **density_series 由生成器内置占用模型产出**（到达 → 入口/十字路口/热点 → 停留后离开）；
  8.4 后可用 `TickEngine` 真实时序替换，字段不变。
- **gate 字段**在入口节点语义完整；非入口节点按同一密度规则派生，仅供训练辅助特征，
  门闸异常检测请以入口节点（G01~G04）为准。
- **等级阈值**：density < 0.3 low，< 0.6 medium，< 0.9 high，≥ 0.9 critical。
- **采样间隔**：`sample_interval=60`（1 分钟），对齐 D 文档建议；生成器可通过参数调整。
- **可复现**：`random_state` 固定即可复现同一份数据。
- **加载示例**：
  ```python
  import pandas as pd
  df = pd.read_csv("data/density_series.csv", dtype={"node_id": str})
  df = df.pivot_table(index="tick", columns="node_id", values="density")
  ```
